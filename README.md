# IRS Audit Assistant

AI-powered chat assistant for KNI Healthcare Services and NPOC financial auditing.

## Features

- 🔒 PIN-protected access
- 💬 Real-time chat with AI
- 📊 Financial data queries
- 📱 Mobile responsive

## Setup

1. Update `CONFIG` in `index.html`:
   - `PIN`: Your access PIN
   - `WEBHOOK_URL`: Your n8n webhook URL

2. Deploy to GitHub Pages

## Tech Stack

- Frontend: HTML/CSS/JS
- Backend: n8n + OpenAI
- Database: Supabase
